# BTech Course Information Page

A basic HTML web page made as a **college assignment** at ABES Engineering College.

## About
This page lists a few B.Tech subjects and course objectives. It was created to practise the fundamentals of HTML.

## What the page contains
- A main heading (`<h1>`) and a short description paragraph (`<p>`)
- An ordered list (`<ol>`) of subjects
- An unordered list (`<ul>`) of course objectives
- A copyright symbol using an HTML entity (`&copy;`)

## Technologies used
- HTML5
- VS Code (editor)
- Git and GitHub (version control)

## How to run
1. Download or clone this repository.
2. Open `index.html` in any web browser.
